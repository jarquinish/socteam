# Referencias — Brand

Aquí se almacenan las **referencias maestras de identidad SOC**.

Nivel en la [jerarquía de fuentes](../source-priority.md): **2 — Identidad
y lineamientos oficiales SOC**.

Aplica a todas las gerencias cuando el entregable utiliza la marca SOC.

---

## Qué puede incluir

- Brandbook vigente
- Sistema visual
- Tipografías
- Paleta
- Logos
- Usos permitidos
- Usos incorrectos
- Fotografía
- Iconografía
- Formas
- Composición
- Tono
- Claims
- Principios de marca

---

## Reglas

- **No extraer reglas inventadas del Brandbook.** Sólo se consideran
  requisitos de marca aquellos que el documento establece
  explícitamente. Lo que el documento no dice no es un requisito.
- Citar siempre la sección o página del documento que sustenta un
  hallazgo.
- Sólo la versión **VIGENTE** genera requisitos obligatorios.
- Las versiones anteriores se conservan en [`archive/`](archive/) con
  estado **ARCHIVADO**. Nunca se borran.

---

## Registro de cada documento de marca

Al incorporar un Brandbook o documento de marca, registrar esta ficha en
este README (sección *Documentos registrados*) y en el
[índice maestro](../reference-index.md):

```
ID:
NOMBRE:
VERSIÓN:
FECHA:
ESTADO:            VIGENTE / ARCHIVADO
FUENTE:            (de dónde proviene el documento)
PROPIETARIO:       (área o persona responsable del documento)
ARCHIVO:           (ruta dentro de /brand)
REEMPLAZA A:       (ID anterior, si aplica)
OBSERVACIONES:
```

Si algún dato no se conoce, escribir "No especificado". No inventarlo.
