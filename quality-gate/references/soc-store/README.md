# Referencias — SOC Store

Referencias que **complementan** las reglas de
[`/rules/soc-store.md`](../../rules/soc-store.md).

---

## Qué puede incluir

- Especificaciones
- Formatos
- Proveedores aprobados
- Criterios de calidad
- Productos
- Materiales
- Márgenes, cuando corresponda
- Producción
- Logística
- Branding de productos
- Ejemplos de productos aprobados (en [`examples/`](examples/))

---

## Reglas

- Registrar cada referencia en el [índice maestro](../reference-index.md)
  con un ID `REF-STORE-000`.
- **No inferir condiciones comerciales que no estén documentadas**
  (márgenes, precios, tolerancias, plazos, condiciones de pago,
  proveedores autorizados). Si no están en una referencia vigente, el
  criterio correspondiente es NO VERIFICABLE.
- Datos que cambian con frecuencia (proveedores, precios, márgenes)
  deben indicar **fecha de actualización** y **vigencia**.
- Sólo las referencias **VIGENTES** generan requisitos obligatorios.
