# Referencias — Contenido

Referencias que **complementan** las reglas de
[`/rules/contenido.md`](../../rules/contenido.md).

Las reglas definen qué criterios revisar; estas referencias aportan la
fuente de verdad para comparar (por ejemplo, contra qué guía de tono se
evalúa el criterio *Tono SOC*).

---

## Qué puede incluir

- Guía de tono
- Mensajes institucionales
- Claims
- Naming
- Mensajes por audiencia
- Criterios editoriales
- SEO
- Ejemplos de copy aprobados (en [`examples/`](examples/))
- Restricciones de lenguaje

---

## Reglas

- Registrar cada referencia en el [índice maestro](../reference-index.md)
  con un ID `REF-CONT-000`.
- Si una referencia de contenido pertenece a una campaña, guardarla en
  la carpeta de esa campaña en [`/campaigns`](../campaigns/), no aquí.
- **No convertir un ejemplo aprobado en plantilla obligatoria.** Un
  ejemplo muestra una forma correcta de resolver, no la única.
- Sólo las referencias **VIGENTES** generan requisitos obligatorios.
