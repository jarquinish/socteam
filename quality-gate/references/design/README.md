# Referencias — Diseño

Referencias que **complementan** las reglas de
[`/rules/diseno.md`](../../rules/diseno.md).

Los lineamientos maestros de identidad (Brandbook) se guardan en
[`/brand`](../brand/). Aquí se guardan las referencias operativas de
diseño.

---

## Qué puede incluir

- Sistemas gráficos
- Plantillas
- Key visuals
- Formatos
- Dimensiones
- Guías de composición
- Sistemas de presentaciones
- Referencias fotográficas
- Adaptaciones aprobadas (en [`examples/`](examples/))

---

## Regla de marca vs. referencia estética

Cada referencia de diseño debe clasificarse en una de estas dos
categorías al registrarse:

| Tipo                      | Qué es                                                                                                         | ¿Puede generar FAIL?                          |
| ------------------------- | -------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| **REGLA DE MARCA**        | Requisito explícito de un documento oficial vigente (Brandbook, sistema visual, especificación técnica, plantilla obligatoria). | Sí, con evidencia.                            |
| **REFERENCIA ESTÉTICA**   | Pieza, moodboard, estilo o ejemplo que orienta el nivel o la dirección visual.                                 | **No, por sí sola.** Puede orientar recomendaciones o la capa de excelencia. |

Si no está claro a qué categoría pertenece, se trata como
**REFERENCIA ESTÉTICA** hasta que Dirección lo defina.

---

## Reglas

- Registrar cada referencia en el [índice maestro](../reference-index.md)
  con un ID `REF-DES-000` e indicar su tipo (regla de marca o referencia
  estética) en la columna *Aplicación*.
- Si una referencia pertenece a una campaña, guardarla en la carpeta de
  esa campaña en [`/campaigns`](../campaigns/).
- Sólo las referencias **VIGENTES** generan requisitos obligatorios.
