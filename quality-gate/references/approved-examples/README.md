# Ejemplos aprobados

Ejemplos que Dirección o las gerencias consideran **buenas referencias
de calidad**.

Nivel en la [jerarquía de fuentes](../source-priority.md): **5 — Ejemplos
aprobados**.

> Los ejemplos sirven para **enseñar calidad**, no para homogeneizar
> todas las entregas.

---

## Organización

```
/approved-examples
  /content
  /design
  /marketing-digital
  /soc-store
```

---

## Reglas

- Un ejemplo **no es una norma**. No se convierte automáticamente en
  regla obligatoria ni en plantilla.
- Un ejemplo **nunca sustenta por sí solo un FAIL**. Puede orientar
  recomendaciones y la capa de excelencia.
- Registrar cada ejemplo en el [índice maestro](../reference-index.md)
  con un ID `REF-EXAMPLE-000`.

---

## Ficha de cada ejemplo

Acompañar cada ejemplo, cuando sea posible, con esta ficha (en un archivo
`.md` con el mismo nombre que el ejemplo):

```
ID:

POR QUÉ FUE APROBADO:

QUÉ RESUELVE BIEN:

QUÉ NO DEBE COPIARSE AUTOMÁTICAMENTE:

CONTEXTO:
(campaña, audiencia, canal, objetivo)

FECHA:

APROBADO POR:
```
