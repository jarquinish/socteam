# Referencias — Corporativo

Información corporativa que debe comprobarse con frecuencia en los
entregables de todas las gerencias.

Nivel en la [jerarquía de fuentes](../source-priority.md): **2 — Identidad
y lineamientos oficiales SOC**, salvo que el brief proporcione
información específica aprobada para la pieza (nivel 1).

---

## Qué puede incluir

- Nombre oficial
- Descripción corporativa
- Líneas de negocio
- Claims corporativos vigentes
- Nombres y cargos
- Datos institucionales aprobados
- Productos
- Información recurrente

---

## Regla de vigencia

La información temporal (cargos, productos, datos institucionales,
claims) debe indicar siempre:

```
FUENTE:
FECHA DE ACTUALIZACIÓN:
VIGENCIA:
```

- **No tratar datos antiguos como vigentes.** Si la vigencia venció o no
  se indica, el dato puede orientar, pero no sustenta un FAIL: el
  criterio de exactitud correspondiente es NO VERIFICABLE hasta
  confirmarlo.
- Registrar cada referencia en el [índice maestro](../reference-index.md)
  con un ID `REF-CORP-000`.

## Referencias registradas

```
ID:                      REF-CORP-001
NOMBRE:                  SOC TEAM — Sistema Operativo de la Dirección de Posicionamiento
ARCHIVO:                 skill-soc-team.md (copia del skill instalado `soc-team`)
FUENTE:                  Skill `soc-team`, registrado por solicitud de Dirección
FECHA DE ACTUALIZACIÓN:  Corte 3T 2026 (según el propio documento)
VIGENCIA:                Vigente. Sus datos CURRENT y PERFORMANCE deben
                         reemplazarse al iniciar 4T 2026.
```

**Uso en Quality Gate:**

- **Puede usarse para:**
  - estructura de gerencias;
  - sistema de clasificación de información (§3);
  - Brand Gate de referencia rápida (§13);
  - datos de autoridad para verificar exactitud, con su fecha de corte.
- **Prioridad frente a otras fuentes:** en marca prevalece REF-BRAND-001.
  En campaña prevalecen REF-CAMP-001 y REF-CAMP-002.
- **No debe usarse para:** evaluar personas. Su modelo de desempeño
  (40/30/20/10), su roster y sus datos de desempeño individual no forman
  parte de la evaluación de entregables. Ver el principio de
  [`quality-gate.md`](../../quality-gate.md#principio).
- Su sección §8 describe un Quality Gate de cuatro niveles (Brand,
  Quality, Strategy, Performance). La relación con este sistema está
  pendiente de definir por Dirección.
