# Índice de revisiones

Índice de todas las revisiones de SOC Quality Gate. Ver
[`README.md`](README.md) para la convención de IDs y nombres.

| ID | Fecha | Gerencia | Proyecto | Tipo de entregable | Versión de entrega | Resultado | Criterios | Revisión anterior | Archivo |
|---|---|---|---|---|---|---|---|---|---|
| — | *Sin revisiones registradas todavía.* | — | — | — | — | — | — | — | — |

### Columnas

| Columna                | Contenido                                                                 |
| ---------------------- | ------------------------------------------------------------------------- |
| **ID**                 | `QG-AAAA-NNNN`.                                                           |
| **Fecha**              | Fecha de la revisión (DD/MM/AAAA).                                        |
| **Gerencia**           | Contenido / Diseño / Marketing Digital / SOC Store.                       |
| **Proyecto**           | Nombre del proyecto según el formulario.                                  |
| **Tipo de entregable** | Según el formulario.                                                      |
| **Versión de entrega** | Primera entrega / Corrección / Versión final.                             |
| **Resultado**          | 🟢 APROBABLE / 🟡 REQUIERE AJUSTES / 🔴 INCOMPLETO.                        |
| **Criterios**          | Versión de criterios aplicada (por ejemplo, `V1`).                        |
| **Revisión anterior**  | ID de la revisión previa del mismo entregable, o "—".                     |
| **Archivo**            | Liga al reporte.                                                          |

El índice no incluye el nombre del responsable. Ese dato permanece
dentro de cada reporte y no se usa para análisis agregados.
