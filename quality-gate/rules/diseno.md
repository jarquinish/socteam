# Reglas — Gerencia de Diseño

Aplica a: piezas gráficas, animaciones, video, presentaciones, materiales impresos y señalética de oficinas.

## Marca
- [ ] Logotipo en versión, proporción y área de protección correctas.
- [ ] Paleta de color del Brandbook SOC.
- [ ] Tipografías institucionales.
- [ ] Elementos auxiliares y estilo fotográfico conforme al sistema visual vigente ("Momento de Vida").

## Composición
- [ ] Jerarquía visual clara: mensaje principal → apoyo → CTA.
- [ ] Legibilidad en móvil (tamaño de texto, contraste).
- [ ] Texto en imagen dentro de lo recomendado por cada red.
- [ ] Zonas seguras respetadas (stories, reels, portadas).

## Técnica
- [ ] Medidas y formato correctos por canal.
- [ ] Resolución adecuada (digital 72 ppi / impreso 300 ppi, CMYK, rebases).
- [ ] Archivos nombrados según convención y con fuentes editables entregadas.
- [ ] Imágenes con derechos de uso o bancos autorizados.

## Accesibilidad
- [ ] Contraste suficiente entre texto y fondo.
- [ ] Texto alternativo propuesto para piezas digitales.

## KPIs de referencia
- Entregas a tiempo, rondas de corrección, alineación de marca en oficinas.
